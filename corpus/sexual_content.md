# Sexually Explicit and Graphic Content

Comment sections beneath news articles are intended for public affairs discussion rather than adult or explicit material. Moderators evaluate sexual references using three outcomes: publish, send to human review, or hide. Context determines whether a comment is legitimate news commentary or inappropriate explicit content.

Any comment containing graphic descriptions of sexual acts, anatomy, or solicitation must be hidden immediately. If a comment discusses sexual health, reproductive policy, or legal cases involving misconduct using clinical or journalistic terminology without graphic detail, publish it; if the wording borders on gratuitous lewdness, send to human review.

For example, if a user posts explicit descriptions of sexual acts beneath an entertainment article, hide the comment immediately. Conversely, if a reader discusses a public health report on teen education using standard medical terms, publish the comment.
