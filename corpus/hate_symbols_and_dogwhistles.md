# Coded Hateful Language and Dogwhistles

Users sometimes evade keyword filters by relying on coded phrases, numeric symbols, or veiled references that signal hostility toward protected groups to insiders while appearing benign to casual readers. Moderators address suspected coded hate using three outcomes: publish, send to human review, or hide. Context and established extremist usage guide these decisions.

When a comment uses recognized numeric hate codes or well-documented extremist slogans alongside derogatory claims about a minority group, hide the comment immediately. If a phrase has both a common innocent meaning and a potential coded meaning—such as a standalone number or historical term—and lacks clear hostile context, send to human review rather than auto-hiding.

For instance, if a commenter replies to an article about immigration with a known white supremacist numeric code and calls for demographic replacement, hide the comment. If a user mentions the number eighty-eight while discussing a classic sports jersey from that year, publish it.
